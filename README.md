# LIVE EVIL 클론코딩

Figma `4003:149` 화면을 HTML, CSS, JavaScript로 구현했습니다. 외부 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

브라우저에서 http://localhost:5173 을 여세요.

- 원본 Figma 이미지 및 SVG를 `assets/`에 저장
- 배너 자동 재생/일시정지, 캐러셀, 더보기, 상품 상세, 검색
- 로컬 저장소를 사용하는 찜과 장바구니
- 모바일 반응형 화면

실제 결제, 회원 인증, 방송 재생 및 서버 API는 포함하지 않은 프런트엔드 데모입니다. DIN Pro와 Noto Sans CJK KR 폰트 파일은 디자인에서 제공되지 않아 시스템 폰트로 대체합니다.

문법 검사: `npm run check`
